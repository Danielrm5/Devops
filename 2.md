# 2.- Fases de Devops

El ciclo de vida de DevOps se representa a menudo como un símbolo de infinito, ilustrando un proceso continuo y sin fin. Las fases principales son:

1.  **Planificación (Plan):** Definición de los requisitos, objetivos y alcance de la nueva funcionalidad o proyecto. Se utilizan metodologías ágiles y herramientas de gestión de tareas.
2.  **Desarrollo (Code):** Los desarrolladores escriben y revisan el código fuente. Se hace un uso intensivo de sistemas de control de versiones como Git para gestionar los cambios.
3.  **Construcción (Build):** El código fuente se compila (si es necesario) y se empaqueta en artefactos desplegables.
4.  **Pruebas (Test):** Se ejecutan pruebas automatizadas (unitarias, de integración, de seguridad) para garantizar la calidad del código antes de pasar a la siguiente fase.
5.  **Despliegue (Deploy):** El código validado se libera y se despliega en los entornos de producción o preproducción de manera automatizada.
6.  **Operación (Operate):** Mantenimiento y gestión de la aplicación en el entorno de producción, asegurando su correcto funcionamiento y escalabilidad.
7.  **Monitorización (Monitor):** Recopilación y análisis de métricas sobre el rendimiento, la disponibilidad y el uso de la aplicación y la infraestructura. Esta retroalimentación es vital para la fase de planificación del siguiente ciclo.
