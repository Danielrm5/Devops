# 3.- Herramientas CI/CD

La Integración Continua (CI) y la Entrega Continua (CD) son prácticas centrales en DevOps, respaldadas por un ecosistema de herramientas especializadas:

*   **Integración Continua (CI):** Es la práctica de integrar frecuentemente el código de todos los desarrolladores en un repositorio central. Cada integración se verifica mediante compilaciones y pruebas automatizadas. Su objetivo es detectar errores lo antes posible.
    *   *Herramientas comunes:* Jenkins, GitLab CI/CD, GitHub Actions, Travis CI, CircleCI.
*   **Entrega Continua (CD):** Extiende la CI asegurando que los cambios en el código (después de pasar las pruebas) estén listos para ser desplegados en producción de manera automatizada y segura. A veces, la CD también incluye el Despliegue Continuo, donde cada cambio que pasa las pruebas se despliega automáticamente en producción sin intervención manual.
    *   *Herramientas comunes:* Además de las mencionadas para CI (que suelen cubrir ambas partes), herramientas como Spinnaker, ArgoCD o herramientas nativas de los proveedores Cloud (AWS CodeDeploy, Azure DevOps).
